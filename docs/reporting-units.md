## 清單統一更新（遷移 0007）

reporting_units 新增 campus_location_id、active 與 contact_note。僅 27 個對應校園地點的項目在新選單啟用，舊單位紀錄及案例外鍵保留。新 API 拒絕選用已停用的單位，但舊案例仍能正常讀取。

能對應通訊錄的項目保留分機，別稱對應時會標示實際電話窗口。其餘未列專屬分機的景點使用已核對的校方總機 08-7703202，並明確標示，不編造地點電話。

通報表單兩欄的資料項目完全相同；大廳搜尋仍保留「既有其他地點」，避免舊自訂地點案件無法搜尋。通報單位與遺失／拾獲地點可各自選擇，不會自動把兩欄的值綁在一起。

資料庫與表單測試已確認兩欄名稱、順序、分組一致，兩種模式可保存新單位，舊目錄保留且停用項目不可新選。表單未列專屬分機時顯示總機說明。

# 通報單位與電話

遺失與拾獲通報共用同一份單位下拉選單，依行政、學務與體育、總務與校園服務、研究與發展，以及各學院分成 10 組，共 138 個單位／服務窗口。更換單位時電話立即更新，未選單位時電話留白。

## 資料來源

校方 PDF：https://ga.npust.edu.tw/docfile/fileDown/PHONKBOOK.pdf
文件頁尾日期：2023/09/08；此次依使用者指定的這個版本整理，不宣稱為最新通訊錄。
總機 08-7703202 依校方聯絡資訊核對：https://ga.npust.edu.tw/

各單位使用總機加分機的格式。優先採辦公室、系辦或服務台；未獨立列辦公室者採該單位在表內的聯絡窗口或主管室分機。沒有把傳真號碼或員工姓名列入單位選單。教學單位、行政組別及常用校園服務都依通訊錄列出，不列每一間個人研究室。

每筆資料保存來源網址、PDF 頁碼、文件日期。固定版本名單保存在 migration 0006，將來更新請新增遷移而非修改已執行的版本。

## 後端與儲存

- reporting_units：單位名稱、分組、電話、分機、來源與排序。
- items.reporting_unit_id：可空外鍵，舊案例保留。
- GET /api/reporting-units：回傳完整目錄，不要求登入。
- POST /api/items：新增 reporting_unit_id。選擇單位後由後端查表帶入 user_name 與 user_contact，避免瀏覽器殘留舊電話。

既有案例的姓名與電話快照不覆寫；沒有提供 reporting_unit_id 的舊 API 客戶端仍可使用原有姓名／聯絡方式欄位。
