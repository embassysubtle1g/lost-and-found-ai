# 正式介面的校園地圖

僅將《遺失物 趴兔.txt》的最新版斜角地圖加入原失物大廳。登記、AI 辨識、媒合及其他分頁保留既有介面。地圖保留已修正的圖書館圓點位置及獨立提示圖層，滑過不搬移圓點，避免取消點擊。

資料庫遷移 0005 建立 campus_locations：27 個地點、5 個分區、示意座標與舊地名別稱。座標是 SVG 畫面座標，並非 GPS。items.campus_location_id 為可空外鍵，舊案例僅在名稱或明確別稱吻合時對應，其他地點保留。

GET /api/locations 回傳資料庫地點。POST /api/items 接受可選 location_id；名稱與編號不符回傳 422。無編號的舊客戶端可繼續提交文字地點，已知名稱會自動關聯。

前端的地圖、地點篩選與登記選單共用地點資料。既有自訂地點保留在「既有其他地點」分組。地圖數字來自實際案例，24 小時與本週熱點使用案例日期時間計算。圈選地點篩選既有案例清單，清除篩選會解除地圖選取。

資料庫遷移已在本機執行。前端已建置；目前若後端仍執行舊程式，重新雙擊原啟動檔會檢查地點 API，並只在 OpenAPI 名稱、8000 埠程序及本專案啟動記錄三者一致時重新啟動主後端。無法確認身分就保留程序、顯示原因。

過渡期間若舊後端回傳 404，介面使用相同的內建地點目錄並提示需要重啟；成功取得 API 後改由資料庫提供地點。此更新不將 v2 原型的模擬 AI、通知或其他功能帶入正式系統。
